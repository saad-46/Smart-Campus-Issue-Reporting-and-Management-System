# Archived setup notes

These four files are the original "CampusIQ" setup notes from early development. They are kept for history and are **superseded**: use the root [README.md](../../README.md) for setup and [../FIRESTORE_RULES_FIX.md](../FIRESTORE_RULES_FIX.md) for the permission model.

| File | What it was |
| --- | --- |
| `README_SETUP.md` | First-run instructions |
| `QUICK_FIREBASE_SETUP.md` | Five-minute Firebase setup |
| `FIREBASE_SETUP_CHECKLIST.md` | Checklist for fixing sign-up problems |
| `SETUP_COMPLETE.md` | Notes after the first Firebase configuration fix |

Do not follow any suggestion in them to paste broad Firestore rules; the real rules are in `firestore.rules` at the repository root and are covered by the rules tests.
